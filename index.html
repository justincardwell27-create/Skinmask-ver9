Skin Mask Mobile V9

Automatic censorship with full-character mode, eye coverage, feathering, corruption, and optional horror pop-ups. No CDN imports.

Runs in your browser. Uses offline illustration-aware detection and optional built-in browser face detection. This is not a trained character-segmentation AI model.

1. Automatic detection

Full-character mode estimates the foreground from image boundaries and skin anchors; it is an experimental background-removal heuristic, not a trained AI model. Complex scenery may be included, and low-contrast characters may be missed. Review before exporting.

Foreground-aware filtering attempts to exclude plain backgrounds and implausibly large warm-colored objects. Hats, tails, clothing, and unusual palettes may still cause errors; this is not trained AI character recognition.

2. Optional correction

Manual tools are just for fixing misses. Automatic censoring remains the default.

3. Effect

Corruption creates sharp black-and-white posterization with neon cyan, magenta and red artifacts, inspired by the V7 0 px glitch you showed.

Optional harsh, fictional subject-classification stamps such as PATHETIC, WORTHLESS SUBJECT, REJECTED, TOTAL FAILURE and DEFECTIVE SUBJECT. The messages refer to the fictional image subject, not the person using the app.

4. On-screen horror notifications

Opt-in only. The messages refer to the fictional image or character, not to the person using this app. No flashing animations. Pop-ups are always dismissible.
